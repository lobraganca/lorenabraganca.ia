# lorenabraganca.ia

Projeto de Lorena Bragança: uma imersão para as pessoas criarem as próprias ferramentas com IA.

O mapa completo do ecossistema está em [ECOSSISTEMA.md](ECOSSISTEMA.md).

A trilha de aceleração (o passo a passo marcável) está publicada em
https://claude.ai/artifact/1NhcuyV66r2fBr5yzeGDMq — o código dela fica em
[trilha/trilha.html](trilha/trilha.html). O progresso marcado mora no banco
da própria página, não neste arquivo.
